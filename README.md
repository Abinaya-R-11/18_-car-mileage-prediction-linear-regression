# Car Mileage (MPG) Prediction using Multiple Linear Regression

An end-to-end Machine Learning regression project built with Scikit-Learn to predict automobile fuel efficiency (Miles Per Gallon - MPG) based on key vehicular specifications.

## 📌 Project Overview

This project implements a multiple linear regression workflow on an automotive dataset (Cars.csv). It rigorously evaluates standard linear regression assumptions (linearity, normality, multicollinearity, homoscedasticity, and residual distribution) before training, evaluating, and serializing the predictive model.
